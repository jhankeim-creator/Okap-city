# Referans vizyèl OKAP CITY

Imaj konsepsyon yo (pa kopi Free Fire) defini idantite a:

- Vil karayibèn: kay koulè, twati tè, palmis, pò, mòn, drapo kòm dekorasyon
- HUD: konpa, minimap won, misyon sou goch, zam/ammo sou dwat, HP/armor, bouton won
- Machin: speedometer, gaz, klakson, antre/soti
- 8 pèsonaj orijinal ak wòl diferan
- Misyon teren: ranmase valiz, antre kay, kondwi, ale Port Okap

MVP Three.js la swiv layout sa. Unity starter nan `unity/Assets/Scripts`.
