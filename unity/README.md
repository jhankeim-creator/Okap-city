# OKAP CITY — Unity 3D Starter

Fondasyon C# ki soti nan pake detay ou voye a. Sèvi ak **Unity 6.x** (pwojè 3D) pou kontinye vèsyon native Android.

MVP playable kounye a kouri nan `src/` (Three.js + Capacitor) paske Unity Editor pa t disponib nan anviwònman sa. De vèsyon yo pataje menm sistèm: player, shooting, bots, loot, safe zone, vehicles, missions, HUD, save.

## Setup Unity
1. Kreye yon pwojè Unity 3D.
2. Kopye `unity/Assets` nan pwojè a.
3. Kreye scene `Main`.
4. Ajoute `GameManager` + `OkapGameManager`.
5. Player capsule + `OkapPlayer` + `OkapThirdPersonCamera`.
6. Zam + `OkapWeapon`, bots + `OkapBot`, loot + `OkapLoot`, machin + `OkapVehicle`.
7. Canvas + `OkapHUD`, disc + `OkapSafeZone`.

## Kontwòl
WASD, Shift, Space, sourit, R, C, E, H, G. Android: `OkapMobileInput`.
